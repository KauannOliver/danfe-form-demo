# DANFE Form Demo

A browser-based form prototype for entering issuer, recipient, transport, and product details into a print-oriented document layout.

**HTML · CSS · JavaScript · Bootstrap**

</div>

## Overview

This educational project demonstrates structured form input, address lookup by postal code, and a printable DANFE-style layout. It is a form and document-layout demo, not an authorized tax-document issuance service.

## Run locally

No build step is defined. Serve the repository directory with `python -m http.server 8000` and open `http://localhost:8000` in a browser. The address lookup requires an internet connection.
